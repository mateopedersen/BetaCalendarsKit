# Boundary test matrix

`BoundaryFixture.leapYears` includes 1900, 2000, 2024, 2027, 2028, 2100, and 2400. The values cover century exceptions and ordinary leap years. `isoWeekTransitions(years:)` and `daylightSaving(timeZoneIdentifier:years:)` create structured reports for week-year and named-zone transitions.
