# Changelog

## 1.0.0 — 2026-10-06

### Added

- Gregorian civil-day values and explicit calendar contexts.
- Compact and fixed six-week month grids with configurable week starts and overflow behavior.
- Twelve-month year grids and inclusive civil-date ranges.
- Structured year, month, leap-day, ISO week-year, and time-zone transition analysis.
- Bounded typed recurrence with explicit missing-date policies.
- Deterministic Codable calendar and boundary fixtures.
- `betacal` command-line tools for grids, recurrence, boundaries, and fixtures.
- DocC guides and strict Swift 6 concurrency-safe value models.
